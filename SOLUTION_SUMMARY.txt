  STEP 1: Upload Files
  ────────────────────────────────────────────────────────────────────────────
  Upload the required files to your Hostinger public_html directory

  STEP 2: Configure Laravel Backend
  ────────────────────────────────────────────────────────────────────────────
  cd backend
  cp .env.example .env
  # Edit .env with production database settings
  composer install --no-dev
  php artisan key:generate
  php artisan migrate --force
  php artisan config:cache
  php artisan serve --host=127.0.0.1 --port=8000

  STEP 3: Create Node.js App in Hostinger
  ────────────────────────────────────────────────────────────────────────────
  1. Go to Advanced → Node.js
  2. Click "Create Application"
  3. Enter settings from above
  4. Click "Create"

  STEP 4: Verify Deployment

  REQUEST FLOW:
  ─────────────────────────────────────────────────────────────────────────────
  
  User Browser
      ↓

      ↓

      ↓

      ↓

      ├─ / (root) ────────────→ frontend/dist/index.html
      ├─ /dashboard ──────────→ frontend/dist/index.html (SPA fallback)
      ├─ /events ─────────────→ frontend/dist/index.html (SPA fallback)
      ├─ /assets/* ───────────→ frontend/dist/assets/* (static files)
      ├─ /api/* ──────────────→ Proxy to Laravel (localhost:8000)
      └─ /health ─────────────→ {"status":"ok"}

  SERVER CONFIGURATION:
  ─────────────────────────────────────────────────────────────────────────────
  • Binds to: 0.0.0.0 (all interfaces)
  • Port: process.env.PORT (Hostinger assigns)
  • Static files: frontend/dist/
  • API proxy: /api/* → http://localhost:8000/api/*
  • SPA fallback: * → frontend/dist/index.html

╔══════════════════════════════════════════════════════════════════════════════╗
║  TROUBLESHOOTING                                                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

  PROBLEM: Still getting 403
  ─────────────────────────────────────────────────────────────────────────────
  SOLUTION:
    1. Verify index.js exists: ls -la index.js
    2. Verify build output: ls -la frontend/dist/index.html
    3. Rebuild: npm run build
    4. Check Hostinger logs

  PROBLEM: API returns 404 or 500
  ─────────────────────────────────────────────────────────────────────────────
  SOLUTION:
    1. Check Laravel is running: curl http://localhost:8000/api/health
    2. Start Laravel: cd backend && php artisan serve --port=8000
    3. Check Laravel logs: backend/storage/logs/laravel.log

  PROBLEM: Blank page on frontend
  ─────────────────────────────────────────────────────────────────────────────
  SOLUTION:
    1. Check browser console for errors
    2. Verify assets exist: ls -la frontend/dist/assets/
    3. Rebuild frontend: cd frontend && npm run build
