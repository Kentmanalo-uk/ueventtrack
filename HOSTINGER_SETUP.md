## 🚀 Deployment Process

### Step 1: Upload Files to Hostinger

Upload these files/folders via FTP or Hostinger File Manager:

```
✅ backend/              (Laravel backend - entire folder)
✅ frontend/             (React source - entire folder including src/)
✅ index.js              (Entry point - REQUIRED)
✅ server.js             (Express server - REQUIRED)
✅ package.json          (Root dependencies - REQUIRED)
✅ .htaccess             (Optional - for Apache fallback)
✅ README.md             (Documentation)
```

**DO NOT UPLOAD:**
- ❌ `node_modules/` (will be installed by Hostinger)
- ❌ `frontend/node_modules/` (will be installed during build)
- ❌ `.env` files (configure separately)
- ❌ `.git/` folder

### Step 2: Configure Laravel Backend

#### A. Create `.env` file in `backend/` folder

```bash
cd backend
cp .env.example .env
```

Edit `.env` with your production settings:

```env
APP_NAME="U-EventTrack"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password

# CORS Configuration
FRONTEND_URL=https://yourdomain.com

# Session Configuration
SESSION_DRIVER=database
SESSION_DOMAIN=.yourdomain.com

# Google OAuth (if using)
GOOGLE_CLIENT_ID=your-client-id
GOOGLE_CLIENT_SECRET=your-client-secret
GOOGLE_REDIRECT_URI=https://yourdomain.com/api/auth/google/callback
```

#### B. Install Laravel Dependencies & Setup

```bash
cd backend

# Install Composer dependencies
composer install --optimize-autoloader --no-dev

# Generate application key
php artisan key:generate

# Run database migrations
php artisan migrate --force

# Optional: Seed initial data
php artisan db:seed --force

# Cache configuration for production
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Create storage symbolic link
php artisan storage:link

# Set proper permissions
chmod -R 755 storage bootstrap/cache
```

### Step 3: Build & Deploy Frontend

Hostinger will automatically run the build command when you deploy. The build process:

1. Installs frontend dependencies: `npm ci --prefix frontend`
2. Builds React app: `npm run build --prefix frontend`
3. Creates `frontend/dist/` with optimized production files
4. Installs Laravel dependencies and creates Laravel caches

You can also manually test the build locally:

```bash
npm run build
```

Verify that `frontend/dist/index.html` exists after build.

### Step 4: Start Laravel Backend

The Laravel backend needs to run on **port 8000** for the proxy to work.

#### Option A: Using PHP Built-in Server (Simple)

```bash
cd backend
php artisan serve --host=127.0.0.1 --port=8000 &
```

#### Option B: Configure as PHP Application in Hostinger (Recommended)

1. Create a subdomain or virtual host in Hostinger
2. Point it to `backend/public/` directory
3. Configure it to run on port 8000
4. Update `LARAVEL_HOST` environment variable if needed

### Step 5: Deploy Node.js Application

1. Go to Hostinger Control Panel → **Advanced** → **Node.js**
2. Click **Create Application**
3. Enter the settings from the table above
4. Click **Create**

Hostinger will:
- Run `npm install` to install dependencies
- Run `npm run build` to build frontend & backend
- Start the server using `node index.js`

### Step 6: Verify Deployment

Test these endpoints:

1. **Frontend Root**: `https://yourdomain.com`
   - Should display React login page
   
2. **Health Check**: `https://yourdomain.com/health`
   - Should return: `{"status":"ok","service":"U-EventTrack"}`
   
3. **API Proxy**: `https://yourdomain.com/api/health`
   - Should return Laravel API response

4. **Static Assets**: `https://yourdomain.com/assets/index-[hash].js`
   - Should load JavaScript files

## 🔍 Troubleshooting

### Issue: 403 Forbidden on Root URL

**Cause**: Frontend not built or `index.js` missing

**Solution**:
```bash
# Verify frontend/dist/index.html exists
ls -la frontend/dist/index.html

# If missing, rebuild:
npm run build

# Verify index.js exists in root
ls -la index.js
```

### Issue: API Returns 404 or 500

**Cause**: Laravel backend not running on port 8000

**Solution**:
```bash
# Check if Laravel is running
curl http://localhost:8000/api/health

# Start Laravel if not running
cd backend && php artisan serve --host=127.0.0.1 --port=8000
```

### Issue: Blank Page / Assets Not Loading

**Cause**: Build didn't complete or paths are wrong

**Solution**:
```bash
# Check if dist folder has files
ls -la frontend/dist/

# Verify assets are present
ls -la frontend/dist/assets/

# Rebuild frontend
cd frontend && npm run build
```

### Issue: CORS Errors

**Cause**: Laravel CORS not configured for production domain

**Solution**:
Edit `backend/.env`:
```env
FRONTEND_URL=https://yourdomain.com
SESSION_DOMAIN=.yourdomain.com
```

Then clear and cache config:
```bash
cd backend
php artisan config:clear
php artisan config:cache
```

### Issue: Database Connection Failed

**Cause**: Database credentials incorrect

**Solution**:
1. Verify credentials in `backend/.env`
2. Test connection:
```bash
cd backend
php artisan tinker
>>> DB::connection()->getPdo();
```
