
### 2. Configure Laravel Backend

```bash
cd backend
cp .env.example .env
nano .env  # Edit with production settings

# Install and setup
composer install --optimize-autoloader --no-dev
php artisan key:generate
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Start Laravel on port 8000
php artisan serve --host=127.0.0.1 --port=8000
```

### 3. Create Node.js App in Hostinger

1. Go to **Advanced** → **Node.js**
2. Click **Create Application**
3. Enter settings from above
4. Click **Create**

Hostinger will automatically:
- Install dependencies (`npm install`)
- Run build command (`npm run build`)
- Start server (`node index.js`)

## 🔧 Technical Details

### Request Flow

```
User Browser
    ↓
https://yourdomain.com/
    ↓
Hostinger Node.js (Express on process.env.PORT)
    ↓
index.js → server.js
    ↓
├─ Static files (/assets/*, /usg-logo.png)
│  └─ Served from frontend/dist/
│
├─ API requests (/api/*)
│  └─ Proxied to Laravel (localhost:8000)
│
└─ All other routes (/, /dashboard, /events, etc.)
   └─ Serve frontend/dist/index.html (SPA fallback)
```

### Server Binding

```javascript
// server.js
app.listen(PORT, '0.0.0.0', () => {
  // Binds to all network interfaces
  // Uses Hostinger's assigned PORT
});
```

- `0.0.0.0` - Binds to all interfaces (required for Hostinger)
- `process.env.PORT` - Uses Hostinger's assigned port
- No hardcoded ports

### SPA Fallback Routing

```javascript
// server.js
app.get('*', (req, res) => {
  const indexPath = path.join(frontendPath, 'index.html');
  res.sendFile(indexPath);
});
```

- Catches all unmatched routes
- Serves `index.html` for React Router
- Enables client-side routing

## 🔍 Troubleshooting

### Still Getting 403?

```bash
# 1. Verify entry file exists
ls -la index.js

# 2. Verify build output
ls -la frontend/dist/index.html

# 3. Check if assets exist
ls -la frontend/dist/assets/

# 4. Test locally
npm run build
PORT=3001 node index.js
# Visit http://localhost:3001
```

### API Errors?

```bash
# Verify Laravel is running
curl http://localhost:8000/api/health

# Check Laravel logs
tail -f backend/storage/logs/laravel.log

# Restart Laravel
cd backend
php artisan serve --host=127.0.0.1 --port=8000
```

### Blank Page?

```bash
# Check browser console for errors
# Rebuild frontend
cd frontend
npm ci
npm run build

# Verify output
ls -la dist/
```
