  HOSTINGER NODE.JS APPLICATION SETTINGS
  U-EventTrack Production Deployment

Copy these exact settings into your Hostinger Node.js application:

───────────────────────────────────────────────────────────────
APPLICATION INFORMATION
───────────────────────────────────────────────────────────────
Application Name:        U-EventTrack
Node.js Version:         22 (or latest LTS available)
Application Mode:        Production

───────────────────────────────────────────────────────────────
BUILD SETTINGS
───────────────────────────────────────────────────────────────
Build Command:           npm run build
Entry File:              index.js

───────────────────────────────────────────────────────────────
DIRECTORY SETTINGS
───────────────────────────────────────────────────────────────
Application Root:        /domains/yourdomain.com/public_html
                        (or your specific path)

Output Directory:        frontend/dist

───────────────────────────────────────────────────────────────
ENVIRONMENT VARIABLES (Optional)
───────────────────────────────────────────────────────────────
Add these if needed:

NODE_ENV=production
LARAVEL_HOST=localhost:8000

Note: PORT is automatically set by Hostinger. Don't add it.

───────────────────────────────────────────────────────────────
FILES TO UPLOAD
───────────────────────────────────────────────────────────────
✅ UPLOAD THESE:
   - index.js (REQUIRED - Entry point)
   - server.js (REQUIRED - Express server)
   - package.json (REQUIRED - Root dependencies)
   - frontend/ (entire folder including src/)
   - backend/ (entire folder)
   - .htaccess (optional)

❌ DO NOT UPLOAD:
   - node_modules/
   - frontend/node_modules/
   - frontend/dist/ (will be generated by build)
   - .env files (create on server)
   - .git/

───────────────────────────────────────────────────────────────
BUILD PROCESS
───────────────────────────────────────────────────────────────
When you deploy, Hostinger will automatically:

1. Run: npm install
   (Installs root dependencies: express, express-http-proxy)

2. Run: npm run build
   Which executes:
   - npm ci --prefix frontend (Install frontend deps)
   - npm run build --prefix frontend (Build React app)
   - composer install --no-dev (Install Laravel deps)
   - php artisan config:cache (Cache Laravel config)
   - php artisan route:cache (Cache routes)
   - php artisan view:cache (Cache views)

3. Run: node index.js
   (Starts the Express server on assigned port)
