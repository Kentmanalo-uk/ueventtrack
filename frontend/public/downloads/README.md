# APK Download Setup

## Instructions

Place your Android APK file in this folder with the exact name:
**`UEventTrack.apk`**

## Steps:

1. **Copy your APK file** to this folder:
   ```
   d:\Ueventtrack\Ueventtrack_2\frontend\public\downloads\
   ```

2. **Rename it to**: `UEventTrack.apk`

3. The "Download App" button in the navbar will now work and download your APK file

## File Location:
```
frontend/public/downloads/UEventTrack.apk
```

## Testing:
- After placing the APK, refresh your browser
- Click the "Download App" button in the navbar
- The APK should download to your Downloads folder

## Notes:
- The APK file must be named exactly `UEventTrack.apk` (case-sensitive)
- Recommended APK size: Under 50MB for faster downloads
- If you update the APK, replace the file with the same name
- Users will get the latest APK when they click download

## Alternative: Use Latest Build Link

If you prefer to always serve the latest EAS build, you can update the button to link directly to your latest EAS build URL instead of hosting the APK file here.
